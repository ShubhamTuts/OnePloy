# Archived upstream workflows

These workflows are retained as migration references only. They are outside
the active GitHub workflows directory, so GitHub does not execute them.

Do not reactivate them unchanged. They target Coolify release channels,
registries, branch conventions, issue automation, and external integrations.
OnePloy must first define its own image registry, signing and provenance policy,
release metadata, upgrade and rollback scripts, environments, and secrets.

The only active workflow in this foundation is
.github/workflows/oneploy-foundation.yml.
